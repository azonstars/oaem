Google Apps Script Deploy Center

To deploy or update your backend code on Google Apps Script, you need to copy the latest code from the main React application. This preview interface is running inside GAS itself and does not provide code export.

How to update GAS Backend:

  1. Open the Main React Application in your local environment or preview link.
  2. Go to System Settings > Apps Script Deploy.
  3. Copy the code for Code.gs, SetupDatabase.gs, and Index.html.
  4. Open your Google Apps Script project (Extensions > Apps Script in your Google Sheet).
  5. Paste and save the copied code into the respective files.
  6. Click Deploy > New deployment to publish changes.
